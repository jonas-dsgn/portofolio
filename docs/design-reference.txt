----------------------------------------------------------------
1. STYLE IDENTITY
----------------------------------------------------------------
- Category:       Minimal / Editorial / Fashion
- Mood:           Dark-contrast, raw, clean, high-end streetwear
- Aesthetic:      Brutalist-lite — strong typography, zero decoration,
                  restrained color palette, uppercase-dominant text
- Inspiration:    Fashion lookbooks, editorial photography portfolios
- Key trait:      The design stays completely out of the way of the
                  photography. Typography does all the heavy lifting.
- The custom crosshair cursor was removed from the current implementation.


----------------------------------------------------------------
2. COLOR SYSTEM
----------------------------------------------------------------
Background (page body):   #D6D6D6   — warm mid-gray
Background (hero):        #202020   — near-black charcoal
Background (lightbox):    rgba(0,0,0,0.92) — near-opaque black

Text — primary:           #111111   — soft black (not pure #000)
Text — secondary:         #333533   — dark warm gray (body copy)
Text — hero/overlay:      rgba(255,255,255,0.85) — off-white on dark bg
Text — hero subtitle:     rgba(255,255,255,0.70) — dimmed white
Text — footer:            #aaa      — light gray

Accent:                   #333533   — same as text-secondary; used for
                                      borders, section title bar, link underlines
Border:                   #333533   — consistent single border color throughout
Card background:          #D6D6D6   — same as page body (flat, no elevation)
Image placeholder bg:     #f5f5f5   — light neutral for unloaded images

RULE: The palette is intentionally achromatic. No color pops.
      Contrast is achieved through dark-on-gray and white-on-dark,
      never through hue. Saturation = 0 everywhere.

6. BORDER SYSTEM
----------------------------------------------------------------
Border color:     #333533 (single color used everywhere)
Border thickness: 1px (all dividers, nav, footer, mobile links)
                  4px (section title left-bar accent only)
                  3px white (portrait image ring)
Border radius:
  - Lightbox image:   2px (barely rounded)
  - Portrait photo:   50% (full circle)
  - All other elements: 0 (sharp, no rounding)

RULE: The design uses almost no border-radius. Sharpness is intentional.
      The only exception is the circular portrait photo.

7. SHADOWS & EFFECTS
----------------------------------------------------------------
Box shadows:
  Lightbox image:   0 20px 40px rgba(0,0,0,0.3)
  Portrait hover:   0 25px 40px -15px rgba(0,0,0,0.2)
  Mobile menu:      -5px 0 20px rgba(0,0,0,0.05) (very subtle)

Blur effects:
  Header:           backdrop-filter blur(10px)
  Lightbox:         backdrop-filter blur(8px)
  Mobile overlay:   backdrop-filter blur(3px)

Hover transitions:
  Nav links:        opacity 0.2s
  Project cards:    all 0.4s cubic-bezier(0.2, 0.9, 0.4, 1.1)
  Project image:    transform 0.6s ease
  Portrait:         transform 0.4s ease, box-shadow 0.4s ease
  Social links:     all 0.2s
  Brand logos:      all 0.3s ease
  Lightbox:         opacity 0.3s ease, visibility 0.3s

Scroll reveal:
  Enter state:      opacity 0, translateY(35px)
  Revealed state:   opacity 1, translateY(0)
  Transition:       opacity 0.8s cubic-bezier(0.2, 0.9, 0.4, 1),
                    transform 0.7s ease
  Trigger:          IntersectionObserver threshold 0.2

About section fade:
  Same pattern — opacity 0 + translateY(30px) → visible class
  Portrait has 0.2s delay relative to text

Card entry animation:
  @keyframes fadeUp — staggered via CSS var --order × 0.1s delay

----------------------------------------------------------------
8. RESPONSIVE BEHAVIOR
----------------------------------------------------------------
Single breakpoint:  768px (mobile ≤ 768px / desktop ≥ 769px)

Mobile changes:
  - Container padding:    2rem → 1.5rem
  - Section padding:      6rem 0 → 4rem 0
  - Hero title:           fluid clamp → hard 3.5rem
  - Hero alignment:       left → center
  - Projects grid:        multi-column → 1 column, gap 2rem
  - About grid:           row → column-reverse (portrait above text)
  - Section title:        left border removed, text-align center
  - Portrait image:       280px max → 220px max
  - Social links gap:     2.5rem → 1.5rem
  - Desktop nav:          hidden (display none)
  - Hamburger:            shown (display flex)
  - Default cursor:       restored (cursor: auto)
  - Mobile menu panel:    activated (slides from right)

Desktop only (≥ 769px):
  - Mobile menu and overlay: display none

----------------------------------------------------------------
10. REPRODUCTION RULES FOR AI
----------------------------------------------------------------
When recreating this style, follow these non-negotiable rules:

1. Font:         Geist only. No substitutes. Load all weights.
2. Color:        Achromatic palette only. #D6D6D6 body, #111111 text,
                 #333533 for all accents/borders. No color.
3. Text:         UPPERCASE everywhere except long body copy.
4. Borders:      1px #333533, sharp corners (0 radius) on all containers.
5. Cards:        Flat — same background as page. No shadow, no elevation.
6. Spacing:      Generous. Sections at 6rem vertical padding minimum.
7. Typography:   Tight letter-spacing on headings (-0.02em to -0.07em).
                 Hero title must be very large and bold (800 weight).
8. Hover states: Always subtle. Translate up + slight scale on cards.
                 Opacity reduction on nav links. Never abrupt.
9. Mobile:       Single breakpoint at 768px. Hamburger menu required.
10. Cursor:      Use the standard cursor on all devices.

ANTI-PATTERNS (do NOT use in this style):
  - No rounded cards or pill buttons
  - No colorful accents or gradients
  - No drop shadows on layout elements (only photos)
  - No Inter, Roboto, or system fonts
  - No centered hero on desktop
  - No filled/background buttons
  - No card elevation via shadow
